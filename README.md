# DealRadar

**DealRadar.no** is a Norwegian affiliate-first deal discovery platform.

> **Core rule: no affiliate link = no DealRadar deal.**

## MVP
- Affiliate product catalog
- Price history
- Evidence-based Deal Score
- Search and categories
- Mobile-first deal pages
- Clear affiliate disclosure
- Automated feed ingestion
- Future price alerts

## Architecture

`Affiliate networks → approved product feeds → product database → price history → deal scoring → published deals → affiliate click`

## Stack

Next.js / TypeScript / PostgreSQL / Vercel

## Current status

MVP homepage and project structure are in development. Product data will remain clearly marked as demo data until approved affiliate feeds are connected.
